# 本地专家 / 联网大模型：App 侧的模型接入与边界

本文记录“本地规则助手 ⇄ 联网大模型”这条链路的架构、**两类 API Key 的区别**，以及 RAG 的待决选项。

## 一、用户看到的两级开关

| 级别 | 入口 | 联网 | 需要什么凭据 |
|---|---|---|---|
| **本地专家** | 助手右上角 `回答方式` → `本地摘要` | ❌ | 无 |
| 在线：团队网关 | `回答方式` → `在线助手设置` → `团队网关` | ✅ | 网关地址 + 网关访问码 |
| **在线：我自己的模型** | `回答方式` → `在线助手设置` → `我自己的模型` | ✅ | 模型服务地址 + 用户自己的 API Key + 模型名 |

三种可以随时互切，切换时助手页会清空对话并提示当前模式，**本地数据不受影响**。

## 二、两类 Key，规则不同（重要）

仓库原有规则写的是“API Key 必须保存在网关，不得进入 App”。这条针对的是**团队的 / 共享的 Key**。用户自带 Key（BYOK）是另一类东西，必须分开表述：

| | 团队的 Key | 用户自己的 Key（BYOK） |
|---|---|---|
| 存放位置 | 只在服务端环境变量 | 只在用户手机内存 |
| 能否在 App 里输入 | ❌ 绝对不行 | ✅ 运行时输入 |
| 能否进源码 / 构建参数 / 仓库 | ❌ | ❌ **同样禁止** |
| 是否经过团队服务器 | 由它自己承载 | ❌ 直连模型，不经过我们 |
| 泄露后果 | 团队账号被盗用、可能产生账单 | 仅该用户自己受影响 |

**结论：“App 里能输入 API Key” ≠ “可以把 Key 打包进 App”。后者依然绝对禁止。**

## 三、为什么“智控台 + 用户自己的 Key”做不到

`xinnan-tech/xiaozhi-esp32-server` 的大模型配置是**服务端级**的：模型配置存在服务端、按智能体绑定，请求里**没有**传用户凭据的入口。所以：

| 想要的 | 智控台能给吗 |
|---|---|
| 角色设定、知识库 RAG | ✅ |
| **团队配置的**大模型 | ✅ |
| **每个用户用各自的 Key** | ❌ **不能** |

要 BYOK，就必须由我们自己的代码调模型 —— 也就是 App 直连（**已实现**）或我们自己的网关（`llm` 模式）。

## 四、RAG 的待决选项

检索必须在“有知识库”的那一方执行。三条路：

| 方案 | 检索在哪 | 生成用谁的 Key | Key 是否经过团队服务器 | 成本 |
|---|---|---|---|---|
| **A. 网关只做检索，App 直连生成** | 我们网关 | 用户的 | ❌ 不经过 | 中：要写切块 + 向量化缓存 + 检索接口 |
| B. 网关检索 + 网关生成 | 我们网关 | 用户的（随请求传入） | ✅ 经过 | 中：检索 + 凭据透传 |
| C. 自建小智 + 智控台 | 小智服务端 | **服务端固定的团队 Key** | 不适用 | 高：智控台（≥0.8.7）+ RAGFlow 单独部署 |

- **A 与 BYOK 及隐私边界最一致**（Key 从不离开手机），代价是 App 要拼 prompt、多一次往返。
- **C 与 BYOK 直接冲突** —— 用不了用户自己的 Key。
- B 最省事，但用户的 Key 会经过团队服务器，属于要正式拍板的隐私取舍。

**当前状态**：App 直连已实现（`DirectLlmAssistantProvider`），**尚未实现任何检索**。在线模式现在只把“本次问题 + 统计摘要”发给模型，不带知识库。

## 五、必须守住的事

- Key 只存**内存**，退出助手页即失效，目前不落盘。若以后要“记住 Key”，**必须用 `flutter_secure_storage`（Android Keystore）**，不能用 `shared_preferences` 明文存储。
- 只允许 HTTPS；仅 debug 版允许本机 HTTP 联调。地址不允许带用户名密码、查询参数或片段；`/chat/completions` 会自动补齐且只补一次。
- **所有失败分支只说固定文案**，绝不回显 Key 或上游响应体 —— 有测试守卫（`mobile_app/test/direct_llm_assistant_test.dart`）。
- 不要在 Wiki、截图、issue、演示视频里出现真实 Key。
- 提示词禁止诊断与剂量建议。这段文本在 App（`mobile_app/lib/assistant/assistant_prompt.dart`）和网关（`gateway.py` 的 `SYSTEM_PROMPT`）**各有一份，改一处必须同步改另一处**。
- 用用户自己的 Key **不等于**可以跳过“每次提问前告知要发送什么”—— 同意开关仍然保留。
- 在线回答同样受安全边界约束：设备动作次数不代表确认服药，不给剂量建议，不修改记录。

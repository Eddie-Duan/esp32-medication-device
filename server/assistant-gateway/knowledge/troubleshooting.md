# 同步错误与故障排查

> 错误码来自 ESP32 固件在同步过程中返回的状态（`firmware/esp32-c3/components/flash/flash.ino` 的 `syncError`）。固件升级后需复核本文件并更新日期。

## 同步时提示 STORAGE_UNAVAILABLE

设备的文件系统不可用（尚未初始化或挂载失败）。**已经保存的记录不会因此被删除。**

处理：由硬件组确认板上无须保留数据后初始化文件系统。**不要在 App 侧尝试"修复"，也不要为了绕过错误去格式化设备。**

## 同步时提示 READ_FAILED

读取某条记录的文件失败。该文件**被保留**，不会被当作已同步删除。

处理：重新同步通常可以重试；若持续失败，交给硬件组检查存储。

## 同步时提示 BAD_FILE

某个文件的大小或内容不符合记录格式（例如文件被截断，或时间字段不是有效时间戳）。该文件**被跳过并保留**。

## 同步时提示 TOO_MANY_FILES

设备上的记录文件数量超过上限（当前固件上限 256 个）。需要先完成同步并提交回收，再继续记录。

## 同步时提示 ACK_TIMEOUT

设备在等待手机确认（ACK）时超时。**记录不会被删除**，重新同步可以继续。

## 为什么有条记录显示时间未知？

记录的时间戳为 0 时视为时间未知，常见原因是设备尚未通过 `SET_TIME` 校时。这类记录**不计入按日统计**。

## 为什么有条记录的时间是"未来"？

记录时间晚于手机当前时间时，会先被排除在按日统计之外。通常是设备时间不准，建议核对设备的时间设置。

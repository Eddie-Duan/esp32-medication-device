# 数据存放与隐私

## 记录保存在哪里？

记录保存在**手机本机**的 SQLite 数据库里。设备记录、演示数据、早期原型时间文本**分别存储**；清除演示数据不会删除设备记录。

## 在线助手会发送什么？

启用在线助手后，每次提问只发送**本次问题**和**统计摘要**（使用动作次数、疑似无效计数、最后同步时间、是否为演示数据）。**不发送**原始记录、时间戳明细、设备标识或历史对话。

## 用自己模型的 API Key 安全吗？

填写自己的模型 Key 时，它只保存在**当前页面内存**中，退出助手页即失效，**不会发送给团队服务器，也不会写入日志**。仓库规则同样禁止把任何 Key 写进源码、APK、构建参数或提交到仓库。

## 如何导出与换手机？

在历史记录页使用"导出 CSV"。数据只存在本机，换手机前请先导出；换机不会自动同步历史记录。

## 没有网络时还能用吗？

可以。本地规则助手完全离线，切回"本地摘要"即可，统计与历史不受影响。若之前使用过在线助手，需要重新配置凭据（凭据不落盘）。

## 换手机或重装 App 后设备会重复吗？

装置按 `device_id + seq` 去重。重新同步同一批记录不会在历史里重复出现。
